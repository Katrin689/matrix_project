# Программа расчета элементов матрицы по формуле синуса

## Назначение
Автоматическое создание матриц размера n на m, расчет элементов по формуле sin(i + j/2) и подсчет строго положительных элементов.

## Требования к окружению
- Операционная система: Windows
- Язык программирования: Python 3.x

## Инструкция по запуску

Для запуска программы выполните следующие шаги:

1. **Откройте терминал** (командную строку Windows или Git Bash).
2. **Перейдите в корневую директорию проекта** (если вы еще не там):
   ```bash
   cd /путь/к/папке/matrix_project
   ```
3. **Перейдите в папку с исходным кодом** `src`:
   ```bash
   cd src
   ```
4. **Запустите программу** с помощью интерпретатора Python:
   ```bash
   python main.py
   ```
5. **Ввод данных:** После запуска программа поочередно запросит ввод данных. Введите целые положительные числа для количества строк и столбцов, нажимая клавишу `Enter` после каждого ввода.

**Пример работы программы:**
```text
строк: 3
столбцов: 3

Матрица:
[1.0, 0.91, 0.6]
[0.6, 0.14, -0.35]
[-0.35, -0.76, -0.98]

Количество положительных элементов: 5
```
